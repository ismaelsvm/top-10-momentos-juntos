TOP 10 MOMENTOS JUNTOS

Para publicar en GitHub Pages:
1. Crea un repositorio público en GitHub.
2. Sube index.html y la carpeta fotos (mantén sus nombres).
3. En Settings > Pages selecciona Deploy from a branch, main, / (root).
4. Espera a que GitHub Pages publique la web y comparte el enlace.

Para agregar tus audios crea una carpeta audio y coloca top-10.mp3, top-9.mp3 ... top-1.mp3.
Nota: la reproducción automática con sonido depende de las políticas del navegador.
